# Alfido Tech Internship - Task 1: Customer Behavior Analysis

This project analyzes 250,000 transaction records across 49,673 customers to evaluate customer behavior, build RFM segmentation, and assess retention and churn risks.

## Project Structure
- `notebook/Task1_Customer_Behavior_Analysis.ipynb`: Executed Jupyter notebook with all code and outputs.
- `task1_customer_behavior_analysis.py`: Standalone Python script for quick local execution.
- `reports/Task1_Report.pdf`: Comprehensive 5-page analysis report.
- `reports/Task1_Submission_Summary.pdf`: Exactly 1-page executive summary document for submission.
- `reports/Task1_Report.docx`: Complete Microsoft Word report document.
- `reports/recommendations.md`: 5 actionable business recommendations.
- `images/`: High-resolution visualization charts.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Run notebook: Open `notebook/Task1_Customer_Behavior_Analysis.ipynb` in Jupyter or Google Colab.
3. Run script: `python task1_customer_behavior_analysis.py`
